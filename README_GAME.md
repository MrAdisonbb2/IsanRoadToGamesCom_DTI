# Karma Loop (Godot 4.7 prototype)

เปิดโปรเจกต์นี้ใน Godot 4.7.1 แล้วกด F5 (ฉากเริ่ม: scenes/title.tscn)

## โครงสร้าง
- scripts/game.gd — Autoload "Game": เซฟ 3 ช่อง, เลือดบอสร่วม, กรรม, ตารางข้อมูลคลาส/มอนสเตอร์/ด่าน, เสียง, ตัวช่วย UI
- scripts/hud.gd — แถบสถานะด้านบน
- scenes/*.tscn + scripts/*.gd — title, save_select, class_reveal, intro, stage_map, shop, event, ending (UI สร้างด้วยโค้ด)
- game_assets/ — asset ที่คัดและแตกออกมาจาก assets/*.zip (ไฟล์ zip ต้นฉบับไม่ถูกแตะ)

## กติกา
- เกม 3 เซฟ กดเซฟว่าง = เกิดทันที สุ่มอาชีพ (อัศวิน/นักธนู/จอมเวท)
- หลอดอาหาร/น้ำ (แยกกัน) ลดลงตามเวลาที่เล่น (อาหารเต็มหลอดอยู่ได้ ~10 นาที น้ำ ~6-7 นาที) ถ้าหมดจะเสีย HP เรื่อยๆ และน้ำหมดทำให้ MP ฟื้นช้าลง · กิน/ดื่มจากกระเป๋าเท่านั้น (ไม่มีปุ่มลัด) · ซื้อได้ที่ร้านค้า ได้จากขอทาน หรือเก็บตามแมพ
- กระเป๋า (กด B): ตาราง 20 ช่อง ช่องละ 9 ชิ้น คลิกช่องแล้วกด "ใช้" · แถว "สกิล" ล่างกระเป๋ามีไอคอนสกิล M1/1/2/3 ชี้เมาส์ดูชื่อ ปุ่ม MP คูลดาวน์ และผลของสกิล (แถบสกิลด้านล่างจอก็มีไอคอน) · ของที่มี: ยา HP, อีเธอร์, สมุนไพร, ผลไม้ป่า, ขนมปัง, เนื้อย่าง, กระติกน้ำ, น้ำผลไม้ + ของเควส · Q/R ยังเป็นปุ่มลัดยา HP/อีเธอร์ (ดึงจากกระเป๋า)
- ของเรืองแสงวางตามห้อง (ห้องละ 1 ชิ้น ยกเว้นห้องมินิบอส/บอส) เดินทับเพื่อเก็บ มอนสเตอร์มีโอกาส 15% ดรอปอาหาร/น้ำ/สมุนไพร
- ทำร้ายชาวบ้านได้ (พ่อค้า ขอทาน คนให้เควส): ฆ่าแล้วกรรม -2 (ติดไปชาติหน้า) และได้ตราบาป +1 (สูงสุด 5) = โดนตีแรงขึ้น 15%/ขั้น หิว/กระหายเร็วขึ้น 20%/ขั้น ร้านขายแพงขึ้น 50% · ร้าน/เหตุการณ์ปิด เควสล้มเหลว · บางครั้งชาวบ้านโต้กลับเป็นบอส bullet hell ที่กระสุนติดคำสาปบาป (ช้าลง + เลือดไหล)
- ห้องบอส/มินิบอส: คัตซีนแบบ Undertale (เดินเข้าหากัน สปอตไลต์ กล่องบทพูดขาว-ดำ พิมพ์ทีละตัว · E/Space/คลิก = ต่อ · Esc = ข้าม) · จอมมาร (ดูบรรทัด "จอมมาร 3 เฟส") เฟสสุดท้ายเกม "crash" (ข้อความ GAME CRASH!!! + ภาพบิดเบือน + จอดำ 3 วิ) แล้วเข้าโหมด Windowkill: ผู้เล่นและบอสอยู่ในหน้าต่าง OS เล็กๆ แยกกันที่เคลื่อนตามตัวละครบนเดสก์ท็อป บอสพุ่งชน/กระโดดทุบทำให้หน้าต่างสั่น และยิงลูกพลังพิเศษที่อยู่ในหน้าต่างของตัวเองพุ่งเข้าหา (ติดคำสาปบาป) · มิโนทอร์พุ่งชนต่อเนื่องและปล่อยคลื่นกระแทก
- ปัดป้อง (F): กางโล่ 0.2 วิ บล็อกกระสุน/การโจมตีทุกแบบ (รวมหน้าต่างลูกพลังของบอสและชาวบ้านโต้กลับ) ได้ HP +20 · คูลดาวน์ 7 วิ · ไอคอนมุมขวาล่างแสดงคูลดาวน์
- คัตซีนเปิดเกม (ทุกครั้งที่เกิดชีวิตใหม่): บ้านท่านผู้เฒ่า เลือก "ได้สิ" = ออกผจญภัย · "ไม่เอา" = บ้านระเบิด ชีวิตนั้นตายทันที (เสียเซฟฟรีๆ)
- จอมมาร 3 เฟส หลอดเลือดแยก 3 หลอด (หลอดละ 1000 ร่วมทุกชีวิต): เฟส 1 bullet hell · เฟส 2 เพิ่มระดับ (ลูกตามตัว, คำสาปแห่งการเกิดใหม่) · เฟส 3 GAME CRASH → หน้าต่าง Windowkill · มีบทพูดตามสคริปต์ทุกเฟส · ชนะแล้วมีคัตซีนจบ: บอสระเบิด ผู้กล้าถูกความมืดกลืนกลายเป็นจอมมารคนใหม่ แล้วจอฟ้าแบบ Windows 10 (ภาษาอังกฤษ เต็มจอ มี QR และโลโก้) นับถึง 100% แล้วรีสตาร์ทกลับหน้าแรก (ลูปใหม่)
- เล่นเกม: ดับเบิลคลิก Play_Game.bat (เปิดเต็มจอ) หรือกด F5 ใน editor (ปิด "Embed Game on Next Play" ไว้แล้ว เกมจึงเปิดเป็นหน้าต่างแยกและเต็มจอ ถ้าเปิดในแท็บ Game ของ editor จะเต็มจอไม่ได้)
- เกมเปิดแบบเต็มจอเป็นค่าเริ่มต้น (F11 สลับเต็มจอ/หน้าต่าง) · ตอนบอสเฟส 3 (Windowkill) หน้าต่างเกมหลักจะย่อลง ให้เดสก์ท็อปจริงเป็นพื้นหลัง เหลือแค่หน้าต่างเล็ก (ชื่อหน้าต่างบอก HP) บทพูดเฟส 3 ขึ้นเป็นหน้าต่างของตัวเอง · F10 = กู้หน้าต่างเกมกลับมาถ้าติด · จบแล้วกลับเต็มจอ
- มีตัวละครที่ยังมีชีวิตได้ทีละตัว: ต้องรอให้ตัวปัจจุบันตายก่อน จึงจะเกิดในเซฟว่างถัดไปได้
- ตาย = เซฟล็อกถาวร ลบ/แก้ไม่ได้ จนกว่าจะมีคนฆ่าบอส หรือตายครบ 3 เซฟ
- เลือดบอส 3 หลอด (หลอดละ 1000) ใช้ร่วมกันทุกเซฟ ชีวิตถัดไปจะเจอบอสที่เฟสล่าสุดที่ค้างไว้ บอสอ่อนลงตามเลือดที่เหลือ (Game.boss_power)
- ขอทาน: ทำดี -> ชีวิตถัดไปได้เงิน/ยา/HP เพิ่ม, ทำเลว -> ชีวิตถัดไปมอนเยอะขึ้น XP มากขึ้น เงินน้อยลง
- ตายแล้วทิ้งหลุมศพไว้ในด่านที่ตาย ชีวิตถัดไปเก็บเงิน/ATK ได้
- ฆ่าบอส -> ฉากจบ ผู้กล้ากลายเป็นจอมมารตนใหม่ เริ่มลูปใหม่ (บอสแข็งขึ้น 15%/ลูป)
- ตายครบ 3 เซฟ -> ทุกเซฟปลดล็อก บอสฟื้นเลือดเต็ม

เซฟอยู่ที่ saves/saves.json ข้างเกม (ข้าง project.godot หรือข้าง .exe) · ลบได้ในหน้าเลือกเซฟ: "ลบเซฟนี้" / "ลบเซฟทั้งหมด" (กดซ้ำเพื่อยืนยัน) · ทดสอบอัตโนมัติให้ตั้ง KARMA_SAVE_DIR เพื่อไม่ให้ทับเซฟจริง
ทดสอบ: ในหน้าเซฟกด Ctrl+Shift+R เพื่อล้างเซฟทั้งหมด (สำหรับนักพัฒนา)
